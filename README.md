# Математический кабинет в Telegram

**Инженерный кейс · EdTech · Telegram Mini App**

Ученик получает домашнее задание и отправляет решение в Telegram. Преподаватель проверяет работу в своём кабинете и оставляет обратную связь. Родитель может посмотреть прогресс через отдельного бота.

## Один цикл работы

| Ученик | Преподаватель | Родитель |
| --- | --- | --- |
| Открывает задание и отправляет решение | Проверяет работу и при необходимости возвращает её на исправление | Смотрит результаты ребёнка |

## Инженерные решения

- **Общий статус задания.** Ученик видит результат проверки в своём кабинете, а родитель получает актуальный отчёт при следующем запросе.
- **Разделение ролей.** У ученика и преподавателя разные интерфейсы. Доступ к операциям проверки и исправления ограничивается на стороне базы данных.
- **Исправления с историей.** В экспериментальной версии преподаватель может исправить результат с указанием причины. Журнал сохраняет историю, а устаревшее изменение отклоняется, если запись уже обновилась.
- **Безопасная разработка.** Для экспериментов используется отдельная среда со своим ботом и базой. Для журнала предусмотрены браузерные и SQL-проверки на регрессии.

## Как я использую AI в разработке

Разбиваю работу на небольшие задачи с критериями приёмки и передаю агенту контекст по нужной части системы. Изменения интерфейса и проверки доступа рассматриваю отдельно. Для изменений в журнале критерии включают сохранение истории, обновление итогов и защиту от перезаписи устаревших данных.
